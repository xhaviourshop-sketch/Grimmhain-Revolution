# Game-Changing Features (10x Mode)

Find transformative product opportunities — not incremental improvements.

**Core question:** "What would make this 10x more valuable?"

**Critical principle:** 10 features that add 1% each ≠ 1 feature that adds 10x. Focus on value concentration.

## Process

### Step 1: Understand Current Value

Map what exists:
- What problems does this solve today?
- Who are the users and what are their core jobs?
- What's the single most important action users take?
- What are the top 3 pain points?
- Where do users drop off or get frustrated?

### Step 2: Find 10x Opportunities

Organize ideas by effort:

| Scale | Examples |
|-------|---------|
| **Massive** (6+ months) | Platform shifts, new business models, category creation |
| **Medium** (1–3 months) | Major workflow improvements, powerful integrations |
| **Small** (< 2 weeks) | Friction removal, automation of repetitive tasks |

### Step 3: Exploration Categories

Systematically examine each:

| Category | Question to Ask |
|----------|----------------|
| **Speed** | What takes users too long? What could be instant? |
| **Automation** | What do users do manually that could be automated? |
| **Intelligence** | What decisions could AI/ML make for users? |
| **Integration** | What tools do users switch between? |
| **Collaboration** | What's currently solo that could be shared? |
| **Personalization** | What's one-size-fits-all that could be tailored? |
| **Visibility** | What's hidden that users wish they could see? |
| **Confidence** | Where do users hesitate or second-guess? |
| **Delight** | What would make users recommend this unprompted? |
| **Access** | What's currently hard to reach or use? |

### Step 4: Evaluate Ruthlessly

Score each idea (1–10) on:

| Dimension | Question |
|-----------|---------|
| **Impact** | How much does this improve user outcomes? |
| **Reach** | How many users benefit? |
| **Frequency** | How often do users need this? |
| **Differentiation** | Does any competitor do this? |
| **Defensibility** | How hard to copy once built? |
| **Feasibility** | How hard to build? |

**Score = (Impact × Reach × Frequency) / Difficulty**

### Step 5: Prioritize

| Category | Criteria |
|----------|---------|
| **Do Now** | High score, low effort, high confidence |
| **Do Next** | High score, medium effort, clear path |
| **Explore** | High potential, needs more research/validation |

