# Asset-Pfade (Grimmhain)

**Verbindlich für neuen Code und neue Assets:**

| Bereich | Pfad |
|--------|------|
| Icons, Bilder, Fonts (Spiel) | `assets/icons/`, `assets/fonts/` |
| Sounds | `assets/sounds/` |

In `js/ui/audio.js` ist `SOUNDS_BASE = "assets/sounds/"` gesetzt.

**Hinweis:** Falls im Projekt noch ältere Ordner wie `/icons` oder `/Sounds` (ohne `assets/`) existieren, dienen sie nur der Abwärtskompatibilität — bitte keine neuen Dateien dort ablegen, um Verwechslungen zu vermeiden.
