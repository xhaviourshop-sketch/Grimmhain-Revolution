# Grimmhain – Werewolf Reckoning

Spielleiter-Tool für das Kartenspiel Grimmhain.

## Struktur
- `js/core/`   – Spiellogik (portierbar zu React Native)
- `js/ui/`     – Web-spezifisches UI
- `assets/`    – Bilder, Fonts, Sounds
- `css/`       – Stylesheets
- `docs/`      – Dokumentation

## Tech-Stack
HTML + CSS + Vanilla JS → PWA → React Native + Expo (geplant)
